**Input**: Design documents in `specs/019-page-report-downloads/` (plan.md, spec.md, research.md, data-model.md, contracts/download-overlay.md, contracts/sinking-fund-standings.md, contracts/expenses-month.md, quickstart.md)

**Prerequisites**: plan.md, spec.md. One new migration (`sf_standings`) with pgTAP; no table or column changes.

**Tests**: Included. The spec sets measurable outcomes (identical remittance files, owner-only access, print setup, keyboard and error behavior) and the project's definition of done requires lint, typecheck and tests to pass (plus `supabase test db` for the schema change).

**Format**: `- [ ] T### [P?] [Story?] Description with file path`. `[P]` = can run in parallel (different files, no unfinished dependency).

**Rules to keep in view**: money is integer centavos until the writer (pesos, two decimals); new SQL functions start with no EXECUTE for `anon` or `authenticated`, grant `authenticated` explicitly, and `security definer` ones check the caller; never edit a pushed migration; no new dependency; no hex colors or arbitrary sizes in components (tokens only); every screen works at 360 px; read `node_modules/next/dist/docs/` before touching routes or `next.config.ts` (AGENTS.md); run pgTAP only after the owner agrees (no local Supabase; it runs against `rolnet-dev` through the rollback wrapper).
